# UI Component Catalog

静的なHTML/CSS/JavaScriptだけで作られた、操作可能なUIコンポーネントのカタログです。各カードには小さな実演UIがあり、クリック・入力・キーボード操作などで状態変化を確認できます。

このリポジトリはライブラリやアプリケーション本体ではなく、UIパターンの見本・検討・参照のための単一ページです。外部パッケージ、ビルド工程、バックエンドはありません。

## すぐに使う

依存関係のインストールは不要です。次のいずれかで開きます。

- `index.html` をブラウザで直接開く
- ローカルHTTPサーバーでこのディレクトリを配信して `index.html` にアクセスする

クリップボードAPIのようにセキュアコンテキストを必要とするブラウザ機能は、ローカルHTTPサーバー経由で開くとより確実に動作します。クリップボード操作には代替処理も実装されています。

## ディレクトリ構成

```text
ui-component-catalog/
├── index.html   # ページ構造、カタログ項目、各デモのマークアップ
├── styles.css   # 共通テーマ、レイアウト、レスポンシブ設定、デモ用スタイル
├── script.js    # 検索・フィルターと各デモのインタラクション
└── README.md    # このドキュメント
```

## ファイルごとの責務

### `index.html`

- カタログのヘッダー、検索欄、カテゴリーフィルター、コンポーネントカードを定義する
- 各カードに検索対象の `data-tags` を設定する
- 各コンポーネントのデモ用HTMLを保持する
- `styles.css` と `script.js` を読み込む

### `styles.css`

- ダークテーマのカタログ画面とカードグリッドの基本スタイルを定義する
- 画面幅に応じて3列、2列、1列へ切り替えるレスポンシブレイアウトを定義する
- 各コンポーネントの見た目・開閉状態・アニメーションをクラスベースで定義する

### `script.js`

- 全体検索とカテゴリーフィルター、表示件数の更新を行う
- 各デモ要素にイベントリスナーを設定し、クラスやテキストを更新して状態変化を表現する
- `Cmd/Ctrl + K` のコマンドパレット起動や `Escape` でのオーバーレイ閉鎖など、共通のキーボード操作を扱う
- コード例のコピーには `navigator.clipboard` を優先し、使えない環境向けにフォールバックを持つ

## 収録しているUIパターン

カタログは主に次のカテゴリで構成されています。

| カテゴリ | 主な例 |
| --- | --- |
| 入力・フォーム | トグル、チェックボックス、ラジオ、セレクト、日付選択、認証フォーム、パスワード表示、カラーピッカー、コンボボックス、バリデーション、フィルター |
| ナビゲーション | ハンバーガーメニュー、タブ、ページネーション、検索、コマンドパレット |
| 状態・通知 | ステータスバー、トースト、インラインアラート、進捗バー、スピナー、スケルトン、ステッパー |
| オーバーレイ | ツールチップ、ポップオーバー、モーダル、ドロワー、ボトムシート、アクションシート |
| 表示・コンテンツ | アコーディオン、カード、テーブル、チップ、空状態、リスト、カンバン、ログ、ファイル一覧 |
| ダッシュボード | KPI、チャートカード、スパークライン、サービス状態、サマリーストリップ、切替式指標カード |
| ライブラリUI | ライブラリ由来のUIパターンのデモ |

検索欄はカード本文と `data-tags` の両方を対象にするため、日本語・英語のコンポーネント名や関連語で絞り込めます。

## 実装方針

- フレームワークを使わない、ブラウザ標準APIのみの実装です。
- 各デモは独立したDOM範囲で動作するよう、基本的に `querySelectorAll` で該当コンポーネントごとに初期化しています。
- 見た目の状態は `.active`、`.open`、`.selected`、`.show` などのCSSクラスで表現します。
- 新しい項目を追加する際は、HTMLカード、必要なCSS、必要な初期化処理、検索用 `data-tags` をそろえて追加してください。

## 変更時の確認

変更後は少なくとも次を確認します。

1. ブラウザで `index.html` を開き、追加・変更したデモを操作する。
2. 検索・カテゴリーフィルターで該当カードが正しく表示・非表示になることを確認する。
3. JavaScriptを変更した場合は `node --check script.js` で構文を確認する。
4. HTML/CSS/JavaScriptの参照パスを変更した場合は、ブラウザの開発者ツールで読み込みエラーがないことを確認する。
